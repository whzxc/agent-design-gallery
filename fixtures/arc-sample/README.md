# ARC sample

The 51 TSX sources and their tokens, scene modules, artwork and TypeScript configuration are copied unchanged from [agent-remote-control](https://github.com/whzxc/agent-remote-control) at commit `b9e18beb`, under its MIT license. The copy lives in `design/`; generated `.adg/` and `output/` content is excluded.

`design/gallery.json` retains the four curated groups and their source order, with TSX paths. The remaining 14 components and 12 surfaces appear in directory groups. The viewer lays out 132 specimens across nine layer-pure chapter boards. `../arc-sample.layout.json` records the measured forms and reference world layout.

The dedicated legacy SVG viewer sample is `../legacy-svg/`. Neither fixture is included in the npm package.
