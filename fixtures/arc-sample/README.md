# ARC sample

Twenty-five assets copied unchanged from [agent-remote-control](https://github.com/whzxc/agent-remote-control) at commit `39e5cf7`, under its MIT license. `gallery.json` groups them into the four sections the SDG design frames show. `../arc-sample.layout.json` is the reference world layout for this directory.

The design frames in `design/surfaces/` embed these files. Replace them only together with those frames. The npm package does not include this directory.
