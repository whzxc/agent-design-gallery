# Architecture

`src/cli.mjs` dispatches commands; `src/open.mjs` starts the loopback service and opens the default browser. `src/server.mjs` reads an explicitly opened directory, serves built TSX frames and legacy SVGs, watches file changes, and persists local preferences. `public/` contains the standalone viewer. The viewer uses `design/tokens.css` during development and its `public/tokens.css` copy in the package; `prepack` refreshes that copy. `public/icons.js` contains copied Lucide geometry with a 1.75px rendered stroke and no runtime icon dependency.

The viewer fills the window with Canvas 2D and positions floating navigation, menus, dialogs, and inspection controls above it. Camera input and drawing are coalesced into animation frames, independently of navigation rendering. Only artboards intersecting the viewport and its retained drawing margin are rasterized. After 150 ms without camera input, a settled drawing includes a quarter of the shorter viewport dimension on each side; pans translate that canvas until they reach its edge, then refresh it. Zoom changes redraw at the new scale without that margin, preserving constant-width borders. A separate canvas retains the static dot background, rebuilt only when its colors, size or pixel ratio change. During gestures the canvas uses cached preview rasters at the actual display scale; when settled it upgrades previews or draws the original SVG for detail. This avoids rebuilding a component tree or mounting inline SVG trees on every input event.

`public/assets.js` measures explicit outermost form/frame declarations once per file revision and theme in temporary, script-disabled sandbox documents. Bounds are geometric, without shadow expansion. TSX component forms pack in source order with 32px gaps and 48px row gaps, wrapping before 1600px. Legacy SVG sets preserve their source arrangement. Sets have 24px side/bottom and 36px top padding; surface frames receive 16px padding. `public/layout.js` implements pure skyline/row packing and aspect-ratio searches for sections and the world, plus the usable fit area. The reference-size unit test reproduces `fixtures/arc-sample.layout.json`. Layout is independent of camera and floating panels.

Previews are SVG images with cropped viewBoxes, preserving document-local styles, identifiers, filters, and aspect ratios. Top-level legacy annotations are omitted from crops. The inspector shows declared frames and their notes; there is no Full sheet action. `public/labels.js` retains positioned DOM text above the drawing canvas. A pan translates one retained label layer for up to 32px before refreshing visible labels without reading chrome geometry. Scale changes recompute positions and collisions on the next animation frame; gesture completion, settling, viewport changes and chrome changes also rebuild the visible set. Chrome bounds and text metrics are cached, with font readiness clearing text metrics. Captions are tested independently. Asset headings follow the visible canvas edge when their original anchor leaves the viewport, prioritize the selected asset and progressively omit optional timestamps and counts when space is limited. Labels remain accessible to DOM-based comparison. Artboards use their asset's canvas color, a 1px border, and a 2px selection ring.

TSX builds return a dependency list, including imported source modules, artwork and tokens. The browser measures standalone frame documents in script-disabled iframes and wraps their static HTML in SVG foreignObjects for the existing image/LOD pipeline. Local legacy SVG references are embedded recursively. Their dependencies participate in cache invalidation. File versions are per asset. An update invalidates the changed file and known dependents, then sends an SSE notification. The camera belongs to the directory and survives refresh; unchanged regions retain positions while enlarged or new regions move below existing content until Arrange current group is invoked.

The directory tree renders from the manifest before asset preparation. Group expansion and filename search are available immediately; a navigation choice made during preparation runs after layout. Forms from one TSX source share a single sandbox document and its compiled stylesheet. Each form replaces the specimen and restores its declared viewport before fonts, images and bounds are measured, avoiding a document navigation for every form.

Preferences store the camera and selected source, named form and group per directory. The viewer saves selection changes as well as camera input, and flushes pending state with a keepalive request on page hide or backgrounding. Restoring a directory resolves the saved names against its current assets without refitting the camera. The manifest also exposes each source's filesystem `modifiedAt` in milliseconds; canvas headings render that value in the browser's local time zone.

The ephemeral server writes viewer preferences, refreshes ignored editor declarations and binds to `127.0.0.1`. The CLI selects its directory once. Browser mutations are limited to preferences; directory opening and reveal APIs are removed. Asset paths come from discovered source entries; symlinks are not scanned.

`src/hub.mjs` adds the resident loopback hub. `src/hub/registry.mjs` persists registered roots and explicit scan results in `registry.json` under the state directory. Only config-bearing directories are projects. Discovery does not build or watch sources. Project metadata reads current Git state and config compatibility; exact frame counts remain null until a viewer builds all sources. A deterministic slug combines the canonical directory basename with a path hash. `/p/<slug>/` forwards to an on-demand viewer server with isolated project preferences. Relative browser URLs preserve the prefix. A five-minute idle timeout releases the server, watcher and caches; active streaming requests prevent eviction. Root rescans are the only hub mutation.

`src/toolkit/` implements the [v2 contract](design-toolkit.md):

- `config.mjs` discovers project roots and validates version requirements and compare adapters. `project.mjs` scaffolds projects, refreshes editor declarations and selects TSX sources; legacy source SVGs fail with a conversion path.
- `runtime.mjs` is the automatic JSX string runtime. It escapes text/attributes, emits void elements, records Frame metadata and draws pinned Lucide geometry. `runtime.d.ts` supplies JSX, Frame, Icon and capture types; generated asset module declarations cover SVG and raster imports.
- `build.mjs` bundles each TSX entry through esbuild. The resolver maps `sdg` and JSX runtime imports to the installed runtime, confines relative imports to the design directory, and inlines artwork. Imports ending in `?url` embed any file under `design/art/` as a data URL; they retain a normal file dependency for watcher invalidation. Development JSX locations identify forbidden markup. Modules execute at build time and are trusted project code.
- `tokens.mjs` parses the two token blocks and generates an inline reference Tailwind theme. Default palettes, font sizes/families, radii and shadows are removed; spacing remains. Classes are collected from rendered markup, then `compile().build()` produces CSS referencing original token variables. Each frame becomes a standalone HTML document.
- `commands.mjs` loads frames in both themes, checks computed paint, root/capture constraints and geometry, or renders selected frames at the requested device scale. Chromium is loaded only by browser commands.
- Design raster captures use a fresh page and browser context per frame and theme. `render` reuses the browser process and closes each page after its capture; `compare` creates independent design and implementation pages. Replacing a shared page's content retains Chromium image resampling state and can change PNG bytes with render order.
- `document.mjs` reads rendered text lines, fields and clipping for both comparison sides, merging adjacent same-line segments. `text.mjs` pairs equal text nearest-first and compares anchored edges, centers and widths.
- `compare.mjs` applies the fixture environment and Frame capture settings with flag overrides, waits for stable text geometry, captures both sides and writes reports. Browser canvas composes overlays. `--all` adds a linked HTML index and JSON summary.

SDG's repository-only `sdg.config.mjs` starts the server on `fixtures/arc-sample` with temporary state and the explicit states in `fixtures/viewer.mjs`. These servers disable preference persistence. Only a server explicitly given fixture definitions interprets the fixture query parameter; normal installations ignore it. The viewer applies selection, camera, theme, panels, and menus before setting `data-fixture-ready`, and waits for visible previews to draw. The tooltip adapter then hovers Inspector. Fixture modules and sample assets stay outside the npm package.


## Access and instance boundary

`src/http.mjs` defines the shared static shell allowlist and direct-local Host/header check. Static HTML, scripts and package viewer styles contain no project data and are public. Project shells do not start viewers; the first authenticated data request does. `src/hub/auth.mjs` creates the mode-0600 state key, reads the current key for every data request and compares SHA-256 digests with timingSafeEqual. Forwarded requests need Authorization Bearer, X-SDG-Key or a query key; any Forwarded or X-Forwarded-* header disables the loopback Host exemption. No decision depends on peer IP.

`public/auth.js` captures a query key into same-origin localStorage and removes it with history.replaceState. Shared dataFetch adds the header to every data fetch and shows a minimal 401 state. EventSource uses the query-key helper. Rendered SVG/HTML, artwork and previews remain behind the authenticated source fetch and self-contained data/blob URLs. There are no auth cookies or auth redirects. The hub shell fetches its lists and rescan through the same helper.

`src/hub/instances.mjs` is independent of hub startup and registry discovery. `sdg open` registers the actual bound port and health ID after startup, and removes its JSON record on normal or signaled exit. The hub probes each record's PID and health ID, deleting dead/reused records while retaining alive legacy instances as not proxyable. Capability `keyAuth: 1` advertises the instance viewer's header/query auth protocol; without it the instance cannot be proxied. The reverse proxy always uses the instance's own server. Public shell routes use that server's static code; authenticated data and SSE are piped without buffering, with credentials and forwarded headers stripped upstream so the loopback-only instance stays independent of the hub. Only preference POSTs are forwarded. Hub shutdown closes proxy streams without stopping independent instances.

Key rotation is atomic and applies to new requests immediately, including when the hub is already running. Existing authenticated SSE connections retain request-time authorization until reconnect. The nginx contract in README preserves Host, URI prefixes, headers and query keys, always marks forwarded requests, and disables SSE buffering/cache.
