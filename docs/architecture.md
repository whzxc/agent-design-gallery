# Architecture

`src/cli.mjs` dispatches commands; `src/open.mjs` starts the loopback service and opens the default browser. `src/server.mjs` reads an explicitly opened directory, serves SVGs, watches file changes, and persists local preferences. `public/` contains the standalone viewer. The packaged `design/tokens.css` is its only token source. `public/icons.js` contains copied Lucide geometry with a 1.75px rendered stroke and no runtime icon dependency.

The viewer fills the window with Canvas 2D and positions floating navigation, menus, dialogs, and inspection controls above it. Camera input and drawing are coalesced into animation frames, independently of navigation rendering. Only visible artboards draw. During gestures the canvas uses cached preview rasters; when settled it upgrades previews or draws the original SVG for detail. This avoids rebuilding a component tree or mounting inline SVG trees on every input event.

`public/assets.js` measures explicit outermost form/frame declarations once per file revision and theme in temporary, script-disabled sandbox documents. Bounds are geometric, without shadow expansion. Component sets preserve their source arrangement with 24px side/bottom and 36px top padding; surface frames receive 16px padding. `public/layout.js` implements pure skyline/row packing and aspect-ratio searches for sections and the world, plus the usable fit area. The reference-size unit test reproduces `fixtures/arc-sample.layout.json`. Layout is independent of camera and floating panels.

Previews are SVG images with cropped viewBoxes, preserving document-local styles, identifiers, filters, and aspect ratios. Top-level annotations are omitted from crops; Full sheet preserves the original. `public/labels.js` retains positioned DOM text above the drawing canvas. Each camera frame admits only labels that fit their slots and avoid floating chrome and previously admitted labels; a set's form captions appear together. Labels remain accessible to DOM-based comparison. Artboards use their asset's canvas color, a 1px border, and a 2px selection ring.

Local SVG references are embedded recursively. Their dependencies participate in cache invalidation. File versions are per asset. An update invalidates the changed file and known dependents, then sends an SSE notification. The camera belongs to the directory and survives refresh; unchanged regions retain positions while enlarged or new regions move below existing content until Arrange current group is invoked.

The service writes only preferences and binds to `127.0.0.1`. Asset paths come from the scanned directory; symlinks are not scanned. Open-directory, preferences, and reveal operations reject requests from another web origin. Opening an invalid or empty directory preserves the current directory. Projects retain their assets, history, conventions, and approval workflow. SDG has no ARC runtime dependency, account system, collaborative state, or asset import database.

`src/toolkit/` implements the [design toolkit contract](design-toolkit.md): project/config discovery and version requirements, token parsing and SVG shadow filters, generated-region sync, two-theme checks, rendering, text measurement, and fixture comparison. Chromium is loaded dynamically only for browser commands. Compare uses the project adapter to manage its app, resolve fixture environment, await readiness, block requests, and collect additional text; it captures page clips or named elements and writes images plus a text report. Browser canvas composes the overlay without an image-processing dependency.

SDG's repository-only `sdg.config.mjs` starts the server on `fixtures/arc-sample` with temporary state and the explicit states in `fixtures/viewer.mjs`. These servers disable preference persistence. Only a server explicitly given fixture definitions interprets the fixture query parameter; normal installations ignore it. The viewer applies selection, camera, theme, panels, and menus before setting `data-fixture-ready`, and waits for visible previews to draw. The tooltip adapter then hovers Inspector. Fixture modules and sample assets stay outside the npm package.
